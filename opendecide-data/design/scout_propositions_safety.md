# Scout report: yes/no PROPOSITION and SAFETY sources for Noul questions

Scope: source datasets for OpenDecide's generic Noul question ("is this statement true of the state?"), for negation and consistency, and for safety decisions (spam, phishing, toxicity).
Date: 2026-09-25. Environment: macOS, python 3.12, `datasets` 4.8.5, `huggingface_hub` 0.36.2.
Every dataset below was loaded with `datasets` in this environment unless marked NOT LOADED. Row counts come from the HF datasets-server `/size` endpoint, and label counts from `/statistics`. Where those endpoints did not work, the counts come from a full local load.
Raw scout outputs and the scout script are in `design/scout_raw/propositions_safety/` (`scout.py`, `nli.json`, `safety.json`, `extra.json`).

## 0. TL;DR

**Best finds for the consistency claim (claim 1).** Each of these is a human-verified set where the same state gets independently worded questions or hypotheses:

| Set | What it gives | Size (eval-usable) | Licence | Role |
|---|---|---|---|---|
| **BECEL BoolQ** (GitHub `MJ-Jang/BECEL`) | Original question + human-filtered **negated** question (label flips by rule) and **paraphrased** question (label kept) over the same BoolQ-dev passage | 401 negation pairs, 1,076 paraphrase pairs | none stated, so build script + IDs | eval (in-domain if BoolQ-train is trained on) |
| **BECEL SNLI / RTE** | Negated / paraphrased hypotheses over the same premise | SNLI 2,204 neg + 4,406 para; RTE 153 + 248 | none stated | **eval-zero-shot** (SNLI is not in any baseline's listed mix) |
| **BoolQ Natural Perturbations** (`tasksource/boolq-natural-perturbations`) | Clusters of **human-written** perturbed questions on one passage, with **soft labels** from multiple annotators; 898 dev questions add a negator | dev 7,596 rows / 1,656 clusters | AllenAI repo has no licence; BoolQ is CC-BY-SA-3.0; so build script | eval (consistency + calibration) |
| **CondaQA** (`lasha-nlp/CONDAQA`) | Each question asked on 4 edits of the same passage (original / paraphrase / scope / affirmative) | test 7,240 (98.8% YES/NO/DON'T KNOW) | Apache-2.0 | train + eval-in-domain (no passage overlap between splits) |
| **ScoNe** (GitHub `selenashe/ScoNe`, CC0) | 6-way negation-scope contrast groups, including **double negation that cancels** | test 200 groups x 6 = 1,200 | CC0 | **eval-zero-shot** |
| **NaN-NLI** (`joey234/nan-nli`) | Expert-written sub-clausal negation, 258 rows on only 48 premises (cheap to bundle) | 258 | CC-BY-SA-4.0 (HF card) | **eval-zero-shot** |
| **VitaminC** (`tals/vitaminc`) | 2x2 contrastive quadruples (claim, contrast-claim) x (evidence, revised evidence); heavy on numbers and comparisons | test 55,197; 11,174 quadruples | CC-BY-SA-3.0 | train + eval-in-domain (use `revision_type=real` for anything DeBERTa-sensitive) |

**Best finds for calibration (claim 2), with human uncertainty as the target:** UNLI (`Zhengping/UNLI`, subjective probabilities for SNLI pairs, MIT per the card), the BoolQ-NP `soft_label`, the civil_comments `toxicity` (fraction of raters, CC0), and Measuring Hate Speech (per-annotator ordinal ratings, CC-BY-4.0, good for Score).

**Safety sources:**
- **civil_comments** (CC0, soft labels, not in any baseline mix): the best toxicity eval-zero-shot.
- **Jigsaw Toxic Comment (Wikipedia)**: already in both baselines' training lineage, so use it for train only.
- **sms_spam** (CC BY 4.0 per UCI): the best spam eval. It is in the training of DeBERTa *non-`-c`* models, so pick `deberta-v3-large-zeroshot-v2.0-c` as the baseline and it becomes clean.
- **Phishing:** no public phishing set is both human-labelled and clearly licensed. The phishing sets on the Hub are Kaggle re-uploads with provenance labels, and more than half of one is Enron-spam text. Do not use them as gold. Use freshly written, independently verified phishing items, or treat phishing as "spam" via the TREC/CEAS corpora through a build script only.

**Avoid:** ANLI (NC licence, and in both baselines via DocNLI / DeBERTa); jinaai/negation-dataset (negations generated by GPT-3.5 and GPT-4, not human-verified); This-is-not-a-dataset (WordNet templates, no state, ungrammatical); CANNOT, if NaN-NLI is kept as eval (156 of 298 NaN-NLI sentences are inside CANNOT); cybersectony, zefang-liu and ealvaradob phishing sets; it4lia (feature vectors only); lmsys/toxic-chat, except as an NC-flagged eval.

**Critical design findings (measured):**
1. **BoolQ leakage:** 957 of 3,270 BoolQ *validation* rows share their passage with BoolQ *train*, and 116 of 401 BECEL-neg passages are in BoolQ train. If BoolQ train is used, you **must** drop every train row whose passage appears in any eval state.
2. **SetFit/enron_spam leakage:** 378 of 2,000 test rows are exact (normalised) duplicates of train rows.
3. **GLiClass v3 lineage contains MNLI** (v3 logic data + v2-init), **DocNLI** (which is built partly from ANLI), a **Jigsaw toxicity** subset, SetFit/qnli, hate_speech18 and amazon_polarity. None of these can be zero-shot for GLiClass.
4. **The complement rule P(A)+P(not A)=1 only holds when the state decides the question.** Neutral, NOT ENOUGH INFO and DON'T KNOW items break it legitimately: "Is it true that H?" and "Is it false that H?" are both "no". Complement pairs must be built only from decidable items (entailment/contradiction, SUPPORTS/REFUTES, YES/NO). Undecidable items should become a 3-way Choice with an explicit "cannot tell" option.
5. **The "negation word = false" shortcut:** NLI hypothesis-only artifacts correlate negators with contradiction, and every BECEL-neg original is True (so every negated question there is False). A shortcut model can ace BECEL-neg. Always pair it with CondaQA, NaN-NLI, ScoNe and the BoolQ-NP negator perturbations, where negated questions are not always False.
6. **Independence of scoring:** GLiClass uni-encoders score all labels in a single forward pass, so questions can attend to each other. For the consistency eval, run **one question per forward pass**. For Jev, bundled questions per call may also interact. Add a control of 50 pairs sent as separate calls to show that bundling does not change the probabilities.

## 1. Contamination map: what the baselines were trained on

Evidence was taken from the model cards (downloaded) and from the GLiClass paper (arXiv 2508.07662).

**GLiClass v3** (`knowledgator/gliclass-edge-v3.0` has encoder `jhu-clsp/ettin-encoder-32m`; `gliclass-modern-base-v3.0` has encoder `answerdotai/ModernBERT-base`):
- The v3 cards list `BioMike/formal-logic-reasoning-gliclass-2k`, `knowledgator/gliclass-v3-logic-dataset` and `tau/commonsense_qa`.
- The v3 logic-dataset card says its sources are FineWeb, CommonsenseQA, the GLiClass-2k prototype and **nyu-mll/MultiNLI**.
- The paper's post-training streams are CommonsenseQA plus 2k synthetic logic items, `fancyzhx/amazon_polarity` plus FineFineWeb, and **MultiNLI**. Pre-training used a "1.2M example general-purpose dataset (text classification, sentiment, NLI)" whose parts are not listed.
- `knowledgator/gliclass-modern-base-v2.0-init` (the likely ancestor of modern-base) lists: MoritzLaurer/synthetic_zeroshot_mixtral_v0.1, knowledgator/gliclass-v1.0, amazon_polarity, QuestionClassification, **Arsive/toxicity_classification_jigsaw** (the Wikipedia Jigsaw subset), IAB news, **SetFit/qnli**, **nyu-mll/multi_nli**, student-question-categories, tweet_sentiment_extraction, **SetFit/hate_speech18**, **saattrupdan/doc-nli**.
- DocNLI is built from ANLI, SQuAD, CNN/DailyMail, DUC and Curation. Its first row equals ANLI's first row (the Parma trolleybus example), which confirms that ANLI is inside it.
- GLiClass reports "spam" as a **zero-shot benchmark**, so GLiClass was not trained on it. The exact spam set is unnamed; the cross-encoder table calls it `enron_spam`.
- Edge-v3's own pre-training mix is not published. Treat any very common NLI or classification set as *possibly seen* and say so in the paper.

**DeBERTa zero-shot (MoritzLaurer):**
- `deberta-v3-*-zeroshot-v2.0-c`: synthetic Mixtral data plus **MNLI** and **FEVER-NLI** only. This is the cleanest baseline, and **recommended**.
- `deberta-v3-*-zeroshot-v2.0` (no `-c`): adds **ANLI, WANLI, LingNLI** and every dataset with `used_in_v1.1=TRUE` in the overview CSV. That includes **sms_spam**, **wiki_toxic** (Jigsaw Wikipedia), hate_speech_offensive, hatexplain, social_bias_frames, amazon_polarity, imdb, rotten_tomatoes, yelp, app_reviews, emotion, emocontext, empathetic, financial_phrasebank, banking77, massive, ag_news, yahoo, trueteacher, well_formed_query, manifesto and cap_sotu.
- `deberta-v3-large-zeroshot-v1.1-all-33`: the same list (mnli, anli, fever, wanli, ling plus 28 tasks, including `spam` = SMS and `wikitoxic_*`).
- `DeBERTa-v3-base-mnli-fever-anli`: MNLI, FEVER-NLI, ANLI.
- **Not** in any listed DeBERTa mix: SNLI, BoolQ, VitaminC, CondaQA, ScoNe/MoNLI, NaN-NLI, BECEL, civil_comments, Enron-spam, Measuring Hate Speech, UNLI and HANS. These are only "zero-shot" relative to the listed mixes.

## 2. Per-dataset records

Conventions: "rev" is the HF commit SHA at scouting time. **Pin it** in the build script with `revision=`. The Noul mapping gives the deterministic rule from the source label to Noul gold (1 = yes).

### A. Core proposition / NLI sources

#### A1. MultiNLI: `nyu-mll/multi_nli`
- **Load:** `load_dataset("nyu-mll/multi_nli", revision="da70db2af9d09693783c3320c4249840212ee221")`. Parquet, no script. Works.
- **Splits:** train 392,702; validation_matched 9,815; validation_mismatched 9,832.
- **Label:** `label` ClassLabel [entailment, neutral, contradiction]. Train is balanced (130,899 / 130,900 / 130,903); val_m has 3,479 / 3,123 / 3,213.
- **Text:** `premise`, `hypothesis`; `genre` (train genres fiction/government/slate/telephone/travel; mismatched genres verbatim/letters/facetoface/oup/nineeleven). `promptID` groups the 3 hypotheses one worker wrote per premise. This is a natural bundle: one state with 3 Noul questions.
- **Sample:** premise "Conceptually cream skimming has two basic dimensions - product and geography." / hypothesis "Product and geography are what make cream skimming work." / label 1 (neutral).
- **Licence:** mostly OANC (free, permissive). The fiction section is under several permissive licences (card tags cc-by-3.0, cc-by-sa-3.0, mit, other). Laurer classes it as commercially compatible. Commercial use OK; redistribute with attribution and share-alike for SA parts.
- **Label noise:** hypothesis-only artifacts (negators correlate with contradiction). ChaosNLI re-annotated 1,599 low-agreement val_m items with 100 votes each. For **31.8%** of them the new majority differs from the original gold, and 37.8% have a top label share below 0.6. That sample is biased toward hard items.
- **Baselines:** in GLiClass v3 (certain), in every DeBERTa variant, and likely in LLM mixes.
- **Role: TRAIN.** Never zero-shot. val_mismatched can serve as an in-domain genre-shift eval, but it is low priority.
- **Noul mapping:** "Is it true that {H}?": entailment gives 1, contradiction 0, neutral 0. Only entailment and contradiction items may feed complement pairs. Choice form: {true, false, cannot tell}.

#### A2. SNLI: `stanfordnlp/snli`
- **Load:** `load_dataset("stanfordnlp/snli", revision="cdb5c3d5...")`, config `plain_text`. Works.
- **Splits:** train 550,152; validation 10,000; test 10,000.
- **Label:** `label` [entailment, neutral, contradiction]. **Rows with label -1** (no gold consensus): train 785, val 158, test 176. Filter them out.
- **Text:** `premise` (Flickr30k captions), `hypothesis`.
- **Sample:** "This church choir sings to the masses as they sing joyous songs from the book at a church." / "The church has cracks in the ceiling." / neutral.
- **Licence:** CC-BY-SA-4.0. Commercial OK; share-alike on redistribution.
- **Label noise:** the same artifacts as MNLI; captions are short and visual rather than decision-like.
- **Baselines:** not in the GLiClass or DeBERTa listed mixes; likely in LLM mixes.
- **Role: do not train on it.** Keep SNLI out of training so that the SNLI-derived **BECEL-SNLI** and **UNLI** evals stay zero-shot. Raw SNLI adds little over MNLI for training.

#### A3. ANLI: `facebook/anli`
- **Load:** works (`plain_text`, rev 8e4813d8...).
- **Splits:** train_r1 16,946 / dev_r1 1,000 / test_r1 1,000; train_r2 45,460 / 1,000 / 1,000; train_r3 100,459 / dev_r3 1,200 / test_r3 1,200. The dev and test splits are balanced.
- **Label:** `label` [e, n, c]. **Text:** `premise`, `hypothesis`, `reason` (annotator rationale, often empty).
- **Sample:** Parma trolleybus premise / "The trolleybus system has over 2 urban routes" / entailment.
- **Licence:** **CC-BY-NC-4.0, so no commercial use.**
- **Baselines:** DeBERTa non-`-c` and mnli-fever-anli; GLiClass through DocNLI.
- **Role: AVOID.** It fails the licence preference and the zero-shot requirement. At most, use it as an optional "hard adversarial" eval-in-domain row, NC-flagged and built by script.

#### A4. WANLI: `alisawuffles/WANLI`
- **Load:** works (rev 61c95318...).
- **Splits:** train 102,885; test 5,000.
- **Label:** `gold` (string), with values entailment / neutral / contradiction. The train split is neutral-heavy (48,977 / 38,511 / 15,397 n/e/c); test is 2,397 / 1,858 / 745.
- **Text:** `premise`, `hypothesis`; `genre` = generated or generated_revised.
- **Sample:** "For more than a decade, the town has had a curfew for children…" / "…but it is not enforced." / neutral.
- **Licence:** CC-BY-4.0. Commercial OK. Note that the texts were generated by GPT-3 Curie and then human-revised and labelled; mention this for provenance.
- **Label noise:** two workers reviewed each example, with Cohen's kappa 0.60 on unrevised examples. Hard by design; expect more ambiguity than MNLI. 41 of 5,000 test premises are verbatim MNLI-train premises.
- **Baselines:** DeBERTa non-`-c` and v1.1.
- **Role: TRAIN** (subsample and rebalance labels). Its test split could be in-domain eval but is low priority.

#### A5. FEVER-NLI: `pietrolesci/nli_fever` (and `copenlu/fever_gold_evidence`)
- **Load:** both work. `pietrolesci/nli_fever` has train 208,346 / dev 19,998 / test 19,998, where the **test labels are unavailable** (fever_gold_label "not available"). `copenlu/fever_gold_evidence` has train 228,277 / val 15,935 / test 16,039, with labels.
- **Label:** pietrolesci has `label` [e, n, c] plus `fever_gold_label`; copenlu has `label` SUPPORTS / REFUTES / NOT ENOUGH INFO and `evidence` as a list of [page, line, sentence].
- **Quirk:** in pietrolesci, **`premise` holds the claim and `hypothesis` holds the evidence**, which is swapped. Map state = hypothesis and question = premise.
- **Licence:** FEVER is CC-BY-SA-3.0 (Wikipedia); copenlu is tagged cc-by-sa-3.0 and gpl-3.0. The pietrolesci card has none.
- **Baselines:** every DeBERTa variant.
- **Role:** optional TRAIN filler only. VitaminC covers the claim/evidence format better.

#### A6. BoolQ: `google/boolq`
- **Load:** works (rev 35b264d0...). Also available as `aps/super_glue` config `boolq`, which has an unlabelled test split of 3,245.
- **Splits:** train 9,427; validation 3,270.
- **Label:** `answer` bool. Train is 5,874 T / 3,553 F; val is 2,033 T / 1,237 F (62% True).
- **Text:** `question` (lowercase, no "?"), `passage` (Wikipedia, median 82 words).
- **Sample:** "do iran and afghanistan speak the same language" / Persian passage / true.
- **Licence:** CC-BY-SA-3.0 (confirmed in the Google repo README). Commercial OK with share-alike.
- **Label noise:** human accuracy is about 90% in the paper, so roughly 10% of items are ambiguous or noisy. The class imbalance matters for calibration.
- **Leakage (measured):** **957 of 3,270 validation rows share their passage with train**, with 721 distinct shared passages.
- **Baselines:** not in the GLiClass or DeBERTa lists; likely in LLM mixes.
- **Role: TRAIN** (after removing passages used in eval) **plus in-domain eval** through BECEL-BoolQ and BoolQ-NP, which are both built on BoolQ-dev. This is the most natural Noul format available: a passage state and a free yes/no question.

#### A7. VitaminC: `tals/vitaminc`
- **Load:** works (rev be6febb7...).
- **Splits:** train 370,653; validation 63,054; test 55,197.
- **Label:** `label` SUPPORTS / REFUTES / NOT ENOUGH INFO. Test counts are 27,664 / 20,265 / 7,268.
- **Text:** `claim`, `evidence` (a sentence, median 136 chars); `case_id` groups contrastive items; `revision_type` = real (from Wikipedia edits) or synthetic (worker-written contrast).
- **Structure (test):** 16,487 cases; 11,174 are **quadruples** (claim, contrast-claim) x (old evidence, new evidence), and 99.1% of cases contain a label flip. Example: "sold **more than** 4.5 million" vs "**less than** 4.5 million" crossed with evidence "5 million" vs "4 million" gives S/R/R/S. This is ideal for the *math and numbers* and *date comparison* failure modes.
- **FEVER overlap:** every `synthetic` row has a FEVER_id (20,716 in test); `real` rows have none (34,481).
- **Licence:** CC-BY-SA-3.0 (card); the code repo is MIT. Commercial OK with share-alike.
- **Label noise:** the NEI class is ambiguous. Note that "more than X" and "less than X" are contraries, not strict complements (X itself satisfies neither), so do not use them as P+P=1 pairs. Use them as "contrast consistency" (both answers must be right).
- **Role: TRAIN** (from the train split, keeping whole quadruples together) **plus eval-in-domain** (test quadruples). If a zero-shot numbers probe is wanted, keep VitaminC out of training instead. For DeBERTa-sensitive numbers, use only `real` rows.

### B. Negation and consistency sets

#### B1. CondaQA: `lasha-nlp/CONDAQA`
- **Load:** works (rev 3c9caa2f...).
- **Splits:** train 5,832; validation 1,110; test 7,240.
- **Label:** `label` (string), with values YES / NO / DON'T KNOW for 98.1–98.8% of rows. The rest are free spans such as "BRITISH" or "LOWER"; drop those. Test counts: NO 3,457, YES 3,263, DON'T KNOW 431.
- **Text:** `sentence1` = passage (median 699 chars) and `sentence2` = question. Also `original cue`, `original sentence`, `PassageID`, `QuestionID`, and `PassageEditID` (0 original, 1 paraphrase edit, 2 scope edit, 3 affirmative edit).
- **Structure:** the same (PassageID, QuestionID) is asked on up to 4 passage edits (mean 3.5 in test). The label differs across edits in 84% of test groups.
- **Split hygiene:** zero PassageID overlap between splits (measured).
- **Sample:** a Medill veto passage / "Would a reader generally expect that ten or more vetoes had been issued…?" / NO.
- **Licence:** Apache-2.0 (card and GitHub). Passages come from Wikipedia. Commercial OK.
- **Label noise:** five verifiers checked every dev/test item, and the first author checked annotations by hand. Human accuracy is reported at about 92% (from memory of the paper; verify).
- **Baselines:** none listed.
- **Role: TRAIN** (train split, all edits of a passage together) **plus eval-in-domain** (test, sampled by passage group). This is the key source for negation *implications*, as opposed to surface negation. Map DON'T KNOW to 0 on "Is it true…?", exclude it from complement pairs, or use a Choice {yes, no, cannot tell}.

#### B2. ScoNe (Scoped Negation NLI): GitHub `selenashe/ScoNe` (recommended), mirror `tasksource/scone`
- **Load:**
  - The GitHub CSVs load with `load_dataset("csv", data_files=<local path>)` once downloaded; the URLs are `raw.githubusercontent.com/selenashe/ScoNe/main/scone_nli/{train,test}/<condition>.csv`. Note that `load_dataset("csv", data_files=<https URL>)` failed under datasets 4.8.5, so download first.
  - The HF mirror `tasksource/scone` (rev 505ed270...) has train 5,010 / test 1,000, but **drops the condition and group columns**, so prefer GitHub.
- **Splits (GitHub):** 6 conditions (no_negation, one_not_scoped, one_scoped, one_scoped_one_not_scoped, two_not_scoped, two_scoped). Each has train 1,002 and test 200, so the test total is 1,200. Each condition is balanced 100 entailment / 100 neutral.
- **Label:** `gold_label_edited` (for one_scoped the column is `gold_label`), entailment or neutral. **Text:** `sentence1_edited`, `sentence2_edited`; `group_index` / row index links the 6 variants.
- **Sample (two_scoped):** "The statement that the man does not own a dog is false." / "The statement that the man does not own a mammal is false." / entailment. This is exactly the **double-negation** test.
- **Licence:** CC0 (GitHub LICENSE and HF card).
- **Label noise:** labels are deterministic by construction (lexical entailment plus scope rules) and checked by the authors. The one_scoped condition *is* NMoNLI (Geiger et al. 2020).
- **Role: EVAL-ZERO-SHOT.** Do not train on ScoNe or MoNLI. Each row has its own premise, so there is one Jev call per row; sample about 20–30 groups x 6.

#### B3. MoNLI: `tasksource/monli`
- **Load:** works (rev 85852314...). train 1,002, test 200 (NMoNLI only; balanced e/n). Fields: `sentence1`, `sentence2`, `gold_label`, `depth`, lexical items.
- **Licence:** none stated (the HF card and the `atticusg/MoNLI` repo have none). It is derived from SNLI (CC-BY-SA-4.0).
- **Role: AVOID as a separate source.** It is identical in content to ScoNe one_scoped, so use ScoNe (CC0).

#### B4. NaN-NLI: `joey234/nan-nli`
- **Load:** works (rev bb442425...). A single split `train` of **258 rows**. It is really a test suite.
- **Label:** `label` with contradiction 117, entailment 97, neutral 44. **Text:** `premise`, `hypothesis`, plus linguistic annotations (`Construction`, `Construction Subtype`: not all, never, not only, not unexpectedly, …).
- **Sample:** "Not all people have had the opportunities you have had." / "Some people have not had the opportunities you have had." / entailment.
- **Structure:** only **48 unique premises**, so about 48 Jev calls cover all 258 questions.
- **Licence:** CC-BY-SA-4.0 in the HF metadata; the GitHub repo has no licence file.
- **Label noise:** expert-written, small and high quality.
- **Contamination:** 156 of 298 NaN-NLI sentences also occur in CANNOT (measured).
- **Role: EVAL-ZERO-SHOT (take all 258).**

#### B5. BECEL: GitHub `MJ-Jang/BECEL` (NOT on HF)
- **Load:** curl the raw TSVs, then `load_dataset("csv", data_files=<local tsv>, delimiter="\t")`. Loading from the remote URL with the datasets csv builder failed.
- **Files/rows used:**
  - `data/boolq/negational.tsv` 401 (question, question_neg, label, neg_label, tag ∈ {negation 301, antonym 98, rm_negation 2})
  - `data/boolq/semantic.tsv` 1,076 (question, question_paraphrase, label)
  - `data/snli/negational.tsv` 2,204 (hypothesis_neg; label always 0→2)
  - `data/snli/semantic.tsv` 4,406
  - `data/rte/negational.tsv` 153
  - `data/rte/semantic.tsv` 248
  - Also MRPC, WiC, SST-2 and AG-News (additive / semantic), and SNLI symmetric and transitive sets.
- **Construction (paper, COLING 2022):** paraphrases come from QuillBot and were kept only if 3 MTurk annotators averaged similarity ≥ 4/5. Negations come from inserting "not" or from ConceptNet antonym swaps, kept only if the average similarity was ≤ 2, followed by a manual review. Negation sets were built **only from BoolQ items labelled True**, SNLI entailment and RTE entailment, so label flipping is guaranteed by rule.
- **Source splits:** BoolQ-neg and BoolQ-sem questions are all from BoolQ **validation** (100%). 116 of the 401 neg passages also appear in BoolQ train.
- **Overlap with BoolQ-NP:** 286 of 401 neg passages and 509 of 1,076 sem passages are also BoolQ-NP dev passages, and 120 passages have both BECEL neg and sem. Bundle them into one state per passage.
- **Licence:** **none stated.** The underlying data is BoolQ (CC-BY-SA-3.0) and SNLI (CC-BY-SA-4.0). Distribute a build script plus row indices, not the text.
- **Caveat:** the negation originals are always True and the negated questions always False, so a "negator means no" shortcut scores 100% on the flip. Report this set together with shortcut-resistant sets (see TL;DR item 5).
- **Role:** BoolQ subsets are **eval-in-domain** if BoolQ train is used, otherwise zero-shot. SNLI and RTE subsets are **EVAL-ZERO-SHOT**. These are the closest public analogue to the jujumilk3 P(x)+P(not x) audit, but with human-filtered pairs.

#### B6. BoolQ Natural Perturbations: `tasksource/boolq-natural-perturbations`
- **Load:** works (rev c6353325...).

## 3. Deterministic label rules for derived variants

Every derived row carries `group_id` (base item), `variant_type` and `rule_id`.

1. **Source → Noul ("Is it true that X?"):** entailment, SUPPORTS, YES or True gives 1. contradiction, REFUTES, NO or False gives 0. neutral, NEI or DON'T KNOW gives 0 **and** `decidable=false`.
2. **Complement (template negation), rule `NEG_T`:** only when `decidable=true`, gold' = 1 − gold. Keep two disjoint template banks:
   - train bank, e.g. "Is it false that X?" and "Is it not the case that X?"
   - eval bank, e.g. "Would it be wrong to say that X?" and "Is the claim 'X' incorrect?"
3. **Human negation pairs (BECEL-neg, BoolQ-NP negator perturbations, NaN-NLI, ScoNe):** use the human label of each question directly. Complement pairs are only those where both are decidable **and** the labels differ by rule (BECEL) or by human label (NP).
4. **Paraphrase (BECEL-sem, CondaQA paraphrase-edit of the state), rule `PARA`:** gold' = gold.
5. **Double negation (ScoNe two_scoped, and template NEG_T∘NEG_T in eval only):** gold' = gold.
6. **Choice vs Noul agreement:** for decidable NLI items, Choice {true, false, cannot tell} gold = the source label, and Noul "is it true" gold = 1 iff the Choice gold is "true". The consistency metric is |P_choice(true) − P_noul(yes)|. For spam, Choice {spam, not spam} vs Noul "is this spam?".
7. **Safety:** spam gives 1. For civil_comments, gold = 1 iff toxicity ≥ 0.5, with the soft target = toxicity. Injection or distractor text appended to the state **never changes** gold (rule `ATTACK_INVARIANT`).
8. **Soft targets:** the UNLI `label`, BoolQ-NP `soft_label` and civil_comments `toxicity` are stored as `gold_prob` and used for calibration. Hard-label accuracy excludes rows with gold_prob in (0.2, 0.8).

|---|---|---|---|

### EVAL, about 2,000 question rows / about 600 Jev calls (priority 1), plus about 540 rows / 340 calls (priority 2)

| Block | Track | States (calls) | Question rows | Claims tested |
|---|---|---|---|---|

- **Jev budget:** P1 is about 600 calls, leaving about 900 of the 1,500-call cap for Choice, Score, injection and distractor slices. Injection and distractor variants should reuse the sms_spam, civil_comments and BoolQ states.
- **CPU budget:** about 2,600 (state, question) pairs, with states of at most 150 words except CondaQA (about 700 chars). One question per forward pass on GLiClass Edge (32.7M) should finish in minutes on a laptop CPU. This is not benchmarked here; measure it.

### Statistical power (95% CIs)
- **Accuracy:** at n = 300 the half-width is ±4.5 pp at 80% accuracy (±5.7 pp at 50%). At n = 150 it is ±6.4 pp; at n = 1,000 it is ±2.5 pp.
- **Paired model comparisons (McNemar, 80% power):** a 5 pp gap needs about 470–780 items (discordance 15–25%); a 10 pp gap needs about 190. So compare models on pooled Noul blocks (≥ 800 items), not on single small sets.
- **Consistency gap mean|P(A)+P(¬A)−1|:** with SD about 0.2, 200 pairs give ±0.028 and 300 pairs give ±0.023. That is ample against the 0.71–1.42 sums reported in the community audit. P1 yields about 250 human negation pairs, plus template pairs.
- **Coverage at ≤1% error:** with 1,000 auto-accepted decisions and 10 errors, the Clopper-Pearson interval is [0.48%, 1.83%]. Pool all Noul eval rows (about 2,000) for this metric, and report the CI and a bootstrap over groups. **Resample by `group_id`, not by row.**
