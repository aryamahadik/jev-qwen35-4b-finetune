# DENY_CLASSES: reason class of every 3.H deny entry (for the C PREREG amendment)

Generated by `c_src/common/denylist.py classes` (v1.2) from `c_src/common/deny_aliases.json` (sha256 `40eeb47e2f379ea8...`) and the inputs listed in 3.H.1. Regenerate it; do not edit by hand.

**Classes (C_DATA_SPEC.md 3.H.1).** `taint`: the text or labels are unusable for us; denies the dataset as new data, every dataset built on it (declared parents, recursive) and its replay rows. `no_new_rows`: no new rows from it; its text is not tainted, so children pass and replay rows are kept (section 5 licence rules still apply). When the recorded reason is unclear, or mixes a taint reason with a no_new_rows reason, the class is `taint`.

**Label quality (PREREG_FINAL.md A16, ruling b).** An entry rejected only for label quality (silver, distant or automatic labels, or noisy gold) is `no_new_rows`, category `label_quality`: no new rows from it, but datasets built on its text pass (T-REx, so MuSiQue passes) and its replay rows are kept. Contamination, licence, forbidden-task, dev and eval entries stay `taint`. The program reads the recorded reason of every `label_quality` entry and fails the build if it also names a taint reason (licence or terms, OHS / used_sources / avoid / locked, a forbidden task, a test, dev or eval split, the Decision Index, LLM or machine-translated / simulated / synthetic text, Jev, sealed); such an entry keeps its taint category. LLM-written text or labels (`llm_written`) is not a label-quality-only reason and stays `taint`.

**Scope.** `dataset`: the whole dataset. `split`: only its test, dev or eval items are tainted (a dev/eval source or a Decision Index benchmark that has a train split); replay rows from the train split are kept. `part`: one subset, half or per-item filter, applied by a program check (the dataset itself stays IN).

**Replay exception (3.H.3).** A replay source that dev uses as a seen source by design (gate_dev name rule) is kept when that is its only taint reason. Test-split, OHS, licence and Jev reasons always drop.

**Persona seeds (2.1).** O*NET's entry (large_labelsets #9) is `no_new_rows`, so a pack or commit row that declares O*NET as its persona-seed parent passes.

**OHS-3 part.** `ohs3/used_sources.json` is read only inside the program: 111 entries, 34 selected as 'avoid' (fixed selection `avoid_or_locked`: rejected.json texts equate 'locked' with 'avoid to be safe', and A16 ruling c confirms it; the only other choice, `avoid_only`, needs a PREREG amendment) or as OHS-3 sources. All selected entries are class `taint`, category `ohs3_avoid`, scope `dataset`. Their names are withheld; a match prints only `ohs3-avoid`. A checked name is matched directly, and every clear entry it hits also has all its curated aliases checked against the hashed names (so clinc150 and clinc_oos, say, cannot miss each other). Canary check (names rejected.json records as 'avoid'): 7/7 hit.

**Bare platform words (PREREG_FINAL.md A16, ruling a).** A bare platform or text-source word (Wikipedia, Wikidata, Reddit, Twitter, GitHub, arXiv, Zenodo, Hugging Face, Kaggle, OSF, PubMed, news, web, Common Crawl, books, movies, reviews, Stack Exchange) never matches on its own: it is never a derived alias of a hashed entry, and it is not matched in any other way. Real text overlap is caught by the counts-only n-gram decontamination against OHS-1/2/3, the sealed exports, Decision Index test items and JevBench items, run before every freeze. In this build **1 of the 34 selected entries had such a word left out** (count only, a disclosure). Curated aliases are not derived: Stack Exchange stays an alias of its own OHS entry, because its text is the denied source.

**Sealed-suite candidates.** Never listed here; checked only through `--sealed-blocklist` (read in the program's own process, matches print only `sealed-block`). The sealed suite is frozen (A15); with no block-list supplied, sealed text overlap is caught by the counts-only n-gram decontamination against the sealed exports before every freeze (A16 a).

**Totals.** 690 clear entries: 596 `taint`, 94 `no_new_rows`, plus 34 hashed OHS-3 entries (`taint`).
