## 1. What is new since plan v2

The field moved a lot in the 5 weeks since Jev launched (15 Sep 2026). The plan names only Jev, AgentDoG, OpenHands critic, d1-ultra and Horizon-Labs. These are NOT in v2 and matter:

1. **Open "decision model" rivals now exist and are Apache-2.0.**
   - AWS Strands Decider 2B (1 Oct 2026): Qwen3.5-2B-Base torso + ~1M-param pointer head + rank-16 LoRA, 1.9B total, Apache-2.0 code and weights. It ships a `before_tool_call` gating example (two yes/no questions gate a tool call). JevBench public set 0.723 (v19, the reference checkpoint) and 0.779 (v1, Qwen3.5 2B) [author]; RTX 3090 median 115 ms, p95 299 ms [author]. https://github.com/strands-labs/strands-decider ; https://www.thefrontier.dev/articles/strands-decider-2b (3 Oct 2026). Its README says labels came from teacher models (gemma-4-31B-it, Qwen3.5-4B); we must never use it as data (and it breaks our own rule), but it is a legitimate eval-only baseline in our size class.
   - Stanford/NVIDIA CLM-8B (VentureBeat 25 Sep 2026): frozen Qwen3-8B backbone + state/action projection heads, Apache-2.0 weights. Reported [author]: BFCL v4 tool calling 95.2 vs Jev 99.2; DeepSWE verifier (38 held-out tasks) 81.6 vs Jev 71.1; Terminal-Bench 2.1 verifier (30 tasks) 87.6 vs 83.1; verifier latency 4.1-5.7x lower than Jev. Candidates come from frontier models, so it is a coding-verifier competitor. https://venturebeat.com/technology/stanford-and-nvidias-open-clm-8b-caches-reusable-agent-actions-and-runs-up-to-9x-faster-than-jev-in-tests
   - Perplexity Decider v1.1 27B: open weights reported as Apache-2.0 (sources conflict on base and price); AA Decision Index 53.1, When2Call 76.5, WildGuardTest 93.8, $16.53 per 1M tasks, 170 ms [independent, via BenchLM mirror of AA, 15 Oct 2026]. https://benchlm.ai/benchmarks/artificial-analysis-decision-index
   - Hosted-only: Celeris-1 Decision and GLiDE (both appear in AA's 13 Oct article, https://artificialanalysis.ai/articles/artificial-analysis-decision-index), OpenAI Decisions API (6 Oct, GPT-6 Luna, $0.10/M input) and Cloudflare Clef/Clef-flash (by 9 Oct), per https://www.implicator.ai/typesafe-ai-raises-870-million-for-jev-as-openai-amazon-and-cloudflare-ship-rivals/ (9 Oct 2026, press). [refuter edit 18 Oct] The implicator page does NOT mention Celeris, Microsoft-Decision-1, GLiDE, Mercury Decide or Perplexity Decider, so their launch dates, the 'Qwen3.5-9B base' for Microsoft-Decision-1, GLiDE/Fastino and Mercury/Inception are UNVERIFIED here.
2. **Artificial Analysis (AA) Decision Index v1.0 launched 13 Oct 2026** and is now the public scoreboard. When2Call is 25% of it. https://artificialanalysis.ai/articles/artificial-analysis-decision-index ; protocol https://artificialanalysis.ai/methodology/decision-index (3,423 of 3,652 MCQ items, 229 "ask for more info" items removed, four shuffled candidates, highest-probability option scored). This matches plan v2's "AA protocol 3,423".
3. **d1-ultra (Liquid AI, 15 Oct 2026)**: hosted only, $0.042 per M input tokens, output free, size not published ("larger open-weight base"). Liquid claims average 76.7 vs Jev 1.14 69.4 on its own 112-eval suite and calibration error 1.5 vs 2.7 [vendor]. https://gigazine.net/gsc_news/en/20261016-d1-ultra ; https://www.orcarouter.ai/blog/liquid-ai-d1-ultra-decision-index. [refuter edit 18 Oct] Verified as vendor claims; GIGAZINE gives no ECE formula, bins or sample sizes. Conflict: GIGAZINE (16 Oct) says AA scored d1-ultra Decision Index 65 vs 57, while OrcaRouter (16 Oct) says the AA board predates d1-ultra and lists 'Independent score: none yet' and that Jev 1.14 has no public Decision Index row. So any d1-ultra or Jev 1.14 AA row (including the BenchLM mirror numbers below) is UNVERIFIED against AA itself.
4. **Agent-trajectory guards moved fast**: AgentDoG 1.5 (28 May 2026; 0.8B/2B/4B/8B + an unreleased "4B-U"), SingGuard-NSFA (13 Jul 2026), StepGuard (25 Aug 2026, EMNLP 2026), DreamGuard (Aug 2026), Granite Guardian 4.1 8B (Apr 2026), TS-Bench/TS-Guard (ACL Findings 2026). See section 4.
5. **Independent audits of the benchmarks themselves** (these change what a win means):
   - Epoch AI review of BFCL v4, 10 Sep 2026: rated "Flawed", 24 of 50 sampled tasks defective; irrelevance 2 of 5 sampled defective, both false negatives (a correct tool call is scored wrong). https://epoch.ai/benchmarks/berkeley-function-calling-leaderboard/review [independent]
   - "Benchmarking the Benchmarks" (arXiv 2607.02577): 496 expert-checked tasks over BFCL v4, tau2-Bench, LiveMCPBench, MCP-Atlas; 18.5% evaluator-human misalignment. When2Call not covered. https://arxiv.org/abs/2607.02577 [author, independent of the benchmark owners]
   - "Passing the Test You Trained On" (arXiv 2610.03448, 2 Oct 2026): detectors trained on a benchmark's attacks look strong on it; see 4.3. https://arxiv.org/html/2610.03448
6. **Independent number for Claude Code's permission gate now exists** (AmPermBench, 28 Apr 2026): end-to-end FNR 81.0% (95% CI 73.8-87.4), FPR 19.8% on 128 ambiguous DevOps prompts / 253 actions. https://arxiv.org/html/2604.04978v2 [independent]. Anthropic's own table (25 Mar 2026): Stage-1 FPR 8.5% / FNR 6.6%; full pipeline FPR 0.4% (n=10,000 real calls) / FNR 17% (n=52 real overeager actions) / synthetic exfiltration FNR 5.7% (n=1,000). https://www.anthropic.com/engineering/claude-code-auto-mode [vendor]

### 4.3 Evidence that matters for how we read these tables

- Chat guards do not transfer to agent trajectories: Qwen3-Guard ATBench F1 0.8, Llama Guard 3-8B 7.3, Llama Guard 4 12B 41.7 (AgentDoG table); on ATBench-Codex Qwen3Guard-Gen-4B/8B F1 3.9/12.7. This supports v2's "chat guards fail on tool calls". [author]
- The best agent-aware guards are the task-specific ones (AgentDoG, StepGuard, SingGuard). SingGuard shows AgentDoG1.5-FG at 84.76 F1 on its Query set but 56.27 on Response: results swing by benchmark. [author, competitor-run]
- General frontier LLMs are strong on trajectory labels (GPT-5.4 76.7 on ATBench, Gemini-3.1-Pro 97.4 on R-Judge). TraceSafe (COLM 2026) also found general LLMs beat specialised guardrails. v2 already tells the owner "frontier chain-of-thought models" cannot be beaten under our rules.
- Detector scores follow training data, not skill: Sheltron 20.1 on AD-Matched but 95.2 on tau-bench; PIGuard 2.1 vs 95.1 on BIPIA (contaminated by BIPIA training split). "Passing the Test You Trained On" argues a number is only meaningful with an upstream audit; v2's upstream exclusion is the right defence.
- The decision-model league table is moving daily (AA v1.0 launched 13 Oct, d1-ultra 15 Oct). Any "#1" sentence needs a date stamp and a re-pull of the board on publication day.
