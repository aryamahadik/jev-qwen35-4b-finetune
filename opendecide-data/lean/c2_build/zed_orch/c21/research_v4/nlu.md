## 0. Read this first (what the evidence says)

1. **Eval-target check.** The G13 registry draft (sections A-D) names NO general NLU set. The only evidence of which general sets we evaluate on is `research_v3/THINK_MODE_MEASURED.md`: the "Nimble 13 sets" include **squad2, summeval, pubmedqa, civil_comments** (the other 9 are not named in any file I may read), plus a "Decision Index sample". So four corpora below are KNOWN evaluation corpora (SQuAD 2.0, PubMedQA, civil_comments, and SummEval which has no train split). Their train splits are marked OWNER (A61(b) split-aware check, owner-reserved), not ALLOW. For every other row, "eval status" is the public benchmark role of its dev/test split from common knowledge (not source-checked); the orchestrator must still run G13 and the 8.5 pre-mapper on whatever it picks. Public dev/test splits are never to be used, only train.
2. **Hosting platforms get licences wrong.** The Data Provenance audit found licence omission above 72% and error rates above 50% on hosting sites (arXiv 2310.16787, https://arxiv.org/abs/2310.16787, searched 18 Oct 2026). I therefore read the upstream LICENSE or README wherever I could; where the Hugging Face card and the upstream disagree it is written in the row (QuAC, WikiTableQuestions, FEVER, TabFact, OpenBookQA, PIQA, WinoGrande).
3. **ShareAlike is the big policy gap.** The owner's licence list is MIT, Apache, BSD, CC-BY, CC0, ODC-BY (never NC, never GPL/AGPL). CC BY-SA is neither on the list nor banned. Most of the best-known NLU sets are CC BY-SA (SNLI, BoolQ, SQuAD, HotpotQA, Natural Questions, ARC, DROP, FEVER, VitaminC, AmbigQA, Spider, FOLIO, Social Chemistry). I mark these **OWNER-SA** so the owner can rule once, in bulk. Without that ruling, the ALLOW-R5 list has almost no large NLI or reading-comprehension set (see section 9).
4. **Wikipedia-derived text.** Many ALLOW rows quote Wikipedia passages (CC BY-SA text). I did not split this per row; the dataset licence on the card is what the verdict uses. Raise once with the owner together with item 3.
5. **Barred and guarded sources.** A61(a) HITs (gsm8k, hover, isarcasmeval, tydiqa, md_fdc, md_peps, md_worldbank, md_usgs, md_cma) are barred under any id or form: Lila contains GSM8K, so it is DENY; HoVer is built from HotpotQA, so HotpotQA is flagged for 8.5 overlap. The BIG-bench canary guard (F5) means StrategyQA must be taken from the original release, never the BIG-bench copy.
6. **LLM-involved labels** (WANLI, HellaSwag, HH-RLHF, HelpSteer2, WebGPT) are OWNER, never ALLOW, per the no-LLM-generated-data rule.
7. Every ALLOW-R5 row is only a candidate: each still needs an 8.5 pre-mapper PASS, the guards (F1-F10), G13, and the A61(b) check.

**Refuter pass (18 Oct 2026):** rows marked "refuter:" were re-checked against the licence file/card and the paper's data section; the verdict tallies in section 10 and the ALLOW-R5 list in section 9 are SUPERSEDED by the "## Verification" section at the end of this file.
