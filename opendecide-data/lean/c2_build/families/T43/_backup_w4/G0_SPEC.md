# T43 PATCH-VERDICT: G0-lite spec (A42-D 1.1, 3.1-3.3, 13.1; FINAL_PLAN section 3, row 4)

Coding family. Python 3.12 programs whose every function carries a docstring `Equals <expression>.` (its exact intended
result). Choice rows only. Gold is program execution; no model sets a label. No T43 row exists on disk before the OHS-AC freeze.

## 1. Decision, heads and options
- **ll, localisation by line.** One function with a docstring and exactly 6 body lines, shown with a gutter `1 |`..`6 |`.
  "Which numbered line holds the bug?" Closed set `line 1`..`line 6`; the abstain option `none: no line differs` is shown on 35%
  of ll rows (question form `loc_line_n`, else `loc_line`) and is the gold in 1/k of the rows that show it (k = 7), so
  "none" is gold in 5% of the ll rows (kit choiceplan, abstain share 1/k, show_rate 0.35). A "none" row shows the unmutated original
  and a test run in which every test passes.
- **lf, localisation by function.** A module of n = 5-8 functions (patch rows: 4-5) (3-6 list stages, one reducer, the entry `run`/`score`/`process`);
  options are the n function names (+ `none: no function differs`, shown with probability 0.05 (n+1), gold 1/k when shown: 5%).
- **pv, patch verdict.** The shown file (buggy), the tests, the test run, and a unified diff of the whole file. Options
  `fixes the bug` (A), `does not fix the bug` (B), `passes the target test but is still wrong` (C) and, on 16% of pv rows (form
  `pv_d`, rules say a patch may not apply), `does not apply` (D), gold in 1/4 of those rows: **D = 4% of pv rows (bar <= 5%).**
  A/B/C are drawn uniformly (row key). Diff-size bin (changed lines <= 2, 3-4, 5-6, >= 7) is drawn from the row key before the label.
- Row mix: S1 + S4 pv (50%), S2 ll (25%), S3 lf (25%). 1,166 rows in the C2 mix; sealed 500 pv-heavy via sealed_rows (BUILD_NOTES).

## 2. Gold (solver A) and the independent verifier (solver B)
- **Program.** Original O is generated by `templates.py` (14 six-line templates x 3 naming styles in training, every line mutable and repairable in >= 75% of draws; `digit_total`, `lead_trim` and the slice template `tail_top` are S5 only; 3-6 stages x 4 reducers x 4 module
  sizes). The bug is one AST mutation of O (`families/T42/mutate.py`, printed by `ast.unparse`, the same printer as O): training
  ops `off_by_one, wrong_operator, flip_sort, wrong_method, int_float_div` (+ `reorder_stmts` on modules and pv);
  **HELD OUT: `swap_args`, `wrong_slice_bound`** (T42 HELD_OUT_OPS, never injected or used in a patch by S1-S4).
- **Tests.** F2P (1-2 calls on which O and the buggy code differ) and P2P (up to 2 calls on which they agree; none when the mutation changes every output); expected values are O's
  outputs. A test passes iff repr(value) equals the expected literal. Test run = the real run of the buggy code.
- **A (execution).** `executor.py` + `exec_child.py`: venv CPython 3.12, `PYTHONHASHSEED=0`, fresh subprocess (`-S -s -B -P`),
  5 s cap (50 ms per call, 3 timeouts kill a candidate), empty temp dir, no network / writes (audit hook, RLIMIT_FSIZE 0). Two
  independent runs must agree on every shown program and patch (`confirm=True`). Patch classes: D = the strict applier
  (`patching.apply_diff`: every hunk's context and removed lines equal the file at the stated line, offset 0, fuzz 0) fails;
  B = a listed test fails (or load error is excluded); C = all listed tests pass and the patched code differs from O on the G0 grid
  (changed functions + the entry, outcome = value and arguments afterwards, or exception class); A = no difference on the grid.
  **>= 200 seeded property-generated cases per function and patch (240, `random.Random(seed|fn)`, wide ranges) are also run; a
  candidate whose seeded cases find a difference the grid does not is rejected (ambiguous), never relabelled.**
  Localisation gold: the unique line / function whose revert (restoring O's text) makes the failing tests pass (reverting only the
  gold hunk turns F2P green), and the line-head ambiguity guard: no other line has an edit of the repair family R*
  (`repairs.py`) that equals O on the grid, and the inverse of the injected edit is in R*.
- **B (`solver_b.py`, paradigm independent_interpreter).** Own parser of the rendered row; own diff applier; tree-walking interpreter
  `interp_b.py` (vendored from T42 solver B); the original is replaced by its **docstring expression** (the reference semantics;
  tests check O equals it on the grid). Every function is judged modularly: its callees stand for their docstring expressions.
  pv: apply, run the shown tests, then compare every function with its docstring on the G0 grid. lf: the function that deviates (none if
  none). ll: the line whose single R* repair (B's own enumerator) makes the tests pass and the function agree with its docstring.
- **G0 grid.** int arg0 {-5,-1,0,1,2,3,5,8,12,100}; int arg>=1 {-1,2,4,9}; list[int] 14 fixed lists (empty, singles, pairs, repeats,
  negatives, zero, lengths up to 5); str 12 fixed strings; arguments of one function form the product (<= 56 cases).

## 4. Options, patches and balance
Every A / B / C patch has one skeleton: ONE core edit of the shown file + ONE hard-coded guard for the target test (`if <args>: return <value>`
at the top of the entry function) + 0-2 harmless-looking rewrites (operand swaps, `a += b` as `a = a + b`); the number of rewrites is drawn
from the row key, the same for the three labels, so added / removed lines, hunks, token edits and AST delta carry no label. Cores and guards by
label: A the original line (or an equivalent rewrite of it) and the correct value; B a random other edit with a correct or a wrong-valued
guard; C a random edit that keeps the tests green with the correct value. The label of each candidate is its execution class; the first
candidate with the drawn label is kept. D candidates: a patch made for another version (stale content, or hunk numbers shifted) that the
strict applier refuses.
Closed option order: kit `build_closed` plan (gold position uniform, abstain 1/k). Error models: neighbour_line, blame_caller,
trust_target_test, ignore_tests.

## 5. G4 metamorphic relations (checked, never emitted)
(1) reorder the test listing (answer unchanged); (2) add one test that passes before and after (unchanged); (3) add two such
tests (unchanged); (4) pv: append an unused function (unchanged). Twins, equiv format partners, complements and attack lines are
not defined for T43 (no input slots; choice rows only): open item, as T42.

## 6. Budget and code-body exemptions
Mean prompt <= 800 tokens (rules counted twice, 90-130 tokens), max 2,000; rows <= 64 per card. Rows: 1,166 (A42-D 1.1) + 500 sealed.
**Exemptions (A42-D 3.1), each re-derived by both execution runs:** G-SL's number lint does not apply to program-rendered spans (code,
docstring expressions, tests, test run, patch): literal numbers are the programs. Label words (`fix`, `none`) never appear in skins or
wordings; the option texts and rules are program text. G3-H does not apply (no authored narrative: surface text is program text only).
