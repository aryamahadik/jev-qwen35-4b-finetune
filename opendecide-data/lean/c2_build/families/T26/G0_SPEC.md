## 3. Relations and gates
G2 (B = A on every row), G3 (B's parse = plugin.canonical; canonical_for on Mode F), G4 (S23), G-SL (kit gsl), G-LEX
(kit lexicon: unit test + 2/2 extractions, precedence 3/3), G-TW (S20, S21; solver_b.pair_diff re-checks that exactly one
fact differs between twin rows), G15 (loader round trip): `pipeline.build_unit` in memory. Any failure drops the whole
unit (never aborts the build, never relabels); a G4 failure or a confirmed wrong gold is a generator bug (H25).

## 4. What Haiku writes (after A38; never sees questions, options or gold)
- **Packs**: >= 25 training + >= 6 held-out: an invented counterparty (2-3 capitalised ASCII words, no digit, no
  negation cue) + a domain label (5-18 chars of a-z, 0-9, at most one hyphen, >= 4 letters incl. a consonant); clean
  labels carry digits, "rn" / "m", hyphens and double letters in fair shares (S11); a label is admitted only if
  plugin.lookalike succeeds on it with every S3 suffix (so an S11 edit always exists).
- **Skins** (Mode T, >= 75%): the request message only; registers email, chat, memo, ticket, voicemail, sms, letter,
  portal_form + held out it_chat, forwarded_thread; tone half alarming, half plain in every register (fixed per
  authoring item, label-blind). **Slots, verbatim, each exactly once (G-SL count 1-1, H5):** {REQUESTER}
  {COUNTERPARTY} {CHANGE} {REQ_ID}; CHANGE as a verb phrase after "please" / "to"; the text must fit every S2 change
  (no subject-matter words outside {CHANGE}). Never (G-SL CORE + EXTENDED + LABEL_WORDS and their inflections; the
