A state holds from its entry date through the day before the next entry that changes the same state. \"Renewed (or valid) for N days\" dated D makes the item valid from D through its last valid day, the Nth day after D; this replaces any last valid day set by an entry dated before D, even a later one, and nothing else moves the last valid day. From the day after the last valid day the item has lapsed (not valid), and a renewal dated after that makes it valid from its date. A lapse changes neither holder nor status."
